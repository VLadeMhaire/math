# Calculus Interactive Learning Platform

🌐 **Live Site:** https://vlademhaire.github.io/math/

An interactive calculus learning platform with page-flipping lessons, practice quizzes, and a neon blue interface.

## ✨ Features

- **10 Interactive Lessons** - From Accumulations of Change to Integration Techniques
- **Practice Quizzes** - 20 questions per topic with instant feedback
- **Page-Flipping Books** - Realistic 3D book interface
- **Neon Design** - Modern blue theme with animations
- **Responsive** - Works on all devices

## 🚀 Quick Start

1. Visit the live site: https://vlademhaire.github.io/math/
2. Click any lesson to start learning
3. Use Practice page to test your knowledge
4. Navigate books with arrow keys or mouse clicks

## 📁 Files

- `index.html` - Main page
- `style.css` - All styling
- `script.js` - Book functionality
- `practice.html` - Quiz page
- `lesson1.html` to `lesson10.html` - Lessons
